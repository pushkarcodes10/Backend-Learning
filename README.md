# Backend Development Learning

This repository contains my code while learning Backend Development with Node.js and Express.js.

Currently, I am learning:

* Node.js
* Express.js
* REST APIs
* CRUD Operations
* Middleware
* Environment Variables

The code in this repository is for practice and learning purposes as I explore backend development concepts.

## Tech Stack

* Node.js
* Express.js
* Postman

## Run the Project

```bash
npm install
npm start
```

To understand how backend applications and APIs are built using Node.js and Express.js.
