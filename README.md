## 🚀 Key Modules & Topics Covered

### 1. Web Servers (Low-Level)
Located in [`web-server/`](./web-server/), this section covers the creation of native web servers without heavy frameworks. It highlights the difference between Node.js and modern alternatives like Bun.

*   **Node.js Native Server ([`server-node.js`](./web-server/server-node.js))**:
    *   Uses the built-in `http` module.
    *   Demonstrates status codes, headers, and basic routing using `req.url` (e.g., handling `/` and `/ice-tea`).
*   **Bun Native Server ([`server-bun.js`](./web-server/server-bun.js))**:
    *   Uses Bun's ultra-fast native `serve` API.
    *   Demonstrates modern `Request` and `Response` object handling.

### 2. Express.js Framework & APIs
Located in [`express/`](./express/), this directory focuses on constructing a robust REST API using Express.

*   **CRUD Operations**: Implements a complete set of REST endpoints for managing custom data (`teaData`) in memory:
    *   `POST /teas` - Create a new tea item
    *   `GET /teas` - Fetch all tea items
    *   `GET /teas/:id` - Fetch a single tea item by ID
    *   `PUT /teas/:id` - Update an existing tea item
    *   `DELETE /teas/:id` - Remove a tea item
*   **Advanced Logger Integration**:
    *   Combines **Morgan** (HTTP request logger middleware) with **Winston** (universal logging library).
    *   Logs outputs in multiple formats: colorized logs for development console and structured JSON outputs stored in `app.log`.
*   **Environment Configuration**: Uses `dotenv` to load environment variables (like `PORT`) securely.

### 3. Data Modeling with MongoDB & Mongoose
Located in [`MongoDB/`](./MongoDB/), this directory contains design schemas showcasing relational modeling using Mongoose. The database structures represent a multi-layer **Todo Application**:

*   **User Schema ([`user.models.js`](./MongoDB/models/todos/user.models.js))**: Defines users with unique, lowercase usernames and emails, and password length constraints.
*   **Todo Schema ([`todo.models.js`](./MongoDB/models/todos/todo.models.js))**: Implements task content, completion flags, a reference relationship (`createdBy` mapping to `User`), and an array of sub-tasks.
*   **Sub-Todo Schema ([`sub_todo.models.js`](./MongoDB/models/todos/sub_todo.models.js))**: Implements nested sub-tasks linked back to their creators.

## 🛠️ How to Setup & Run

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (version 18+ recommended) or [Bun](https://bun.sh/) installed.

### 1. Running the Native Web Servers
Navigate to the `web-server` directory and execute either:

*   **Node.js**:
    ```bash
    node web-server/server-node.js
    ```
*   **Bun**:
    ```bash
    bun web-server/server-bun.js
    ```
The server will start on `http://127.0.0.1:3000`.

### 2. Running the Express API
Navigate to the `express` directory:
```bash
cd express
```
Install the dependencies:
```bash
npm install
```
Configure environment variables:
Create a `.env` file inside the `express/` folder:
```env
PORT=3000
```
Run in development mode (with hot reloading via nodemon):
```bash
npm run dev
```
Or run in production mode:
```bash
npm start
```
